# Enterprise Home Lab Infrastructure

An enterprise-inspired Home Lab developed through two major iterations.

## Version 1 – LEGO Infrastructure Prototype

A prototype focused on learning and implementing enterprise infrastructure concepts.

## Version 2 – Automated Infrastructure Foundation

A redesigned infrastructure focused on platform engineering and building an Internal Developer Platform (IDP).

**Note:** Version 1 (`v1-lego-infrastructure-prototype`) is fully built and documented. Detailed documentation for both versions can be found in their respective folders. Version 2 (`v2-automated-infrastructure-foundation`) is currently under active development and will be built incrementally. Progress is primarily limited by available funding, as many planned features require purchasing hardware and equipment that I do not currently own.
